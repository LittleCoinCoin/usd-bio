Quick Start
===========

Basic Usage
-----------

Include the USD-Bio extension header:

.. code-block:: cpp

   #include <iostream>
   #include <usd_bio/extension.h>

   int main() {
       std::cout << "USD-Bio v" << usd_bio::GetVersion() << std::endl;
       return 0;
   }
