The figure was the hole in the system. This closes it.

Everything else on the sheet was specified — type, colour, zones, ink. The thing occupying roughly 40% of it, the figure, was left at "Goldilocks, not minimal" and a caption rule. That is not a kit, it is a mood. This plate supplies four chart forms and two claim graphics as renderers: pass in a plain data array, get back an SVG in mm units that already obeys the poster-distance type floor, the stroke floor, the one-accent-event rule, and the Okabe-Ito categorical scale — checked live against whatever theme Plate 02 hands it.

The set is closed on purpose. An open chart library is a stylesheet — infinite variety, no guarantee any instance is legible at 3 m. A closed set of four forms plus two claim graphics is a factory: every chart this system ever produces has already been proved to hold the floor.

Reads on

All four charts and both claim graphics below are regenerated from random data on load and on demand — reroll any one to confirm it is drawing, not displaying a picture. Reroll the theme to confirm every form survives a different hue, chroma and ground tint.

01

The shared grammar

Four rules apply to every form in this kit, before a single chart type is chosen. They are what makes the output a system rather than four unrelated widgets.

RuleApplied as
Direct labels, no legendEvery series, bar and group is named at the mark itself. A detached legend forces the "dance back and forth" the canon already forbids for the two-zone layout — the same defect, smaller scale.
One accent event per figureExactly one bar, one line, one group, or one point may carry --accent. It is the finding. Everything else is ink or ink-soft at reduced weight — a figure that highlights three things highlights nothing.
Categorical colour is checked, not assumedMulti-series forms cycle the Okabe-Ito set in order and verify each entry against the theme's --paper live — see section 02. A low-contrast entry gets a dashed stroke instead of a silent fail.
Type and stroke never go below the sheet's own floor--type-detail (20pt / 5.1mm cap) is the smallest text anywhere in this canon; no chart label may be smaller. Data strokes hold 4× the hairline weight so a line survives a 3m glance.
A scale reference stands in for empty axesAny form that doesn't print a value at every mark (series, dot comparison, distribution) draws light gridlines and 2–3 tick values instead of a bare axis. [Lai & Morrison 2025] — cited in the guidelines' own §7.2 — found charts stripped to necessary-ink-only read worse, not better. Ranked bar's per-bar value label already satisfies this and carries none.

Poster-distance floors and the categorical scale, live

Both are computed, not typed. The stroke and type numbers are constants in the kit; the categorical pass/fail is measured against whichever theme is loaded above.

TokenValueWarrant
chart label floor7.06mm / 20pt[optics] — equal to --type-detail, the sheet's own floor. A caption at 0.6m that is smaller than the sheet allows itself is a defect, not an efficiency.

03

The four forms

Each figure follows §7's lockup: an assertion caption above, stating what to see, then the chart. Reroll any one — the data changes, the rules above hold.

Scale reference — before / after this fix

These three forms used to carry no axis at all — position and length told you order, nothing told you magnitude. Per the guideline's own citation, that is stripped past Tufte, not up to him: a little redundant scaffolding (gridlines, a few tick values) reads easier, not harder. Ranked bar is unchanged — its direct value label already served as the scale.

Chart, or table?

Reach for a table instead of any of the four forms when the reader's task is to look up a specific value (an n per arm, an exact p-value) rather than compare values at a glance — a chart optimises the second task and actively degrades the first. A table with more than ~6 rows or 4 columns at the sheet's type floor rarely fits the evidence zone at a legible size; past that, the honest options are a ranked bar (if one column is the story) or a supplementary handout, not a shrunk table.

What is deliberately not here

No pie, no stacked bar, no dual-axis, no 3-D anything. Each excluded form either encodes its comparison in area or angle (harder to judge at a glance than length or position) or requires a legend to read at all. If a fifth form earns its place, it earns it the same way these four did: one comparison task, one honest encoding, direct labels.

04

The claim graphic — a non-text five-second layer

The billboard has carried the claim in type alone since the format's first version. Half the hall now runs some version of that billboard, so type is no longer differentiating. These two forms encode the same claim a second way, legible at the same 3.6m the takeaway type is built for.

Proportion ring. For a claim shaped "N% of X show Y."

Before / after. For a claim shaped "X halves Y" or "Y triples under Z."

Neither is decoration. Both are redundant encodings of the same number the billboard states in words — exactly the redundancy the canon already requires between colour and underline. Use at most one per poster, next to the takeaway line, never inside the evidence zone where it would compete with the hero figure.

06

Raster figures — the minimum-ppi floor

Micrographs, apparatus photos and rendered stills don't come from this kit — they arrive as files. The one rule that travels with them: a 150dpi image printed at A0 size is very easy to produce by accident and impossible to fix after printing.

effective ppi = px ÷ (mm ÷ 25.4)

  • 150 ppi floor — a hero figure viewed from ~0.6–1m. Below this, halftone dots become visible before the reader is close enough to read the caption.
  • 300 ppi floor — a detail crop meant to be examined closely (a microscopy inset, a zoomed panel). Reserve the higher floor for the parts of the figure actually being scrutinised, not the whole sheet — that is the same Goldilocks judgement §7 already asks for.

Calibrate this against a real print. The 150/300 pair is a printing-industry convention, not something measured off your printer or fabric — Plate 01's ink-budget ceilings carry the same caveat, and both should be checked together on the same test print.

07

What this plate asks you to decide

Three decisions, plus the two invented numbers in section 06.

  1. Four forms, closed. Ranked bar, series, dot comparison, distribution. If your evidence regularly needs a fifth (a network, a map, a matrix), name it — closed sets grow by decision, not by accident.
  2. The claim graphic ships as a real component, not a suggestion. Section 04's two forms go into the kit alongside the charts, with the same "at most one, next to the takeaway" placement rule written into the guidelines.
  3. Categorical colour is proved per-theme, not per-chart. Section 02's strip is the same check every chart runs internally — if you'd rather a hard-fail (refuse to render) instead of the dashed-stroke fallback, that's a one-line change here.
  4. 150 / 300 ppi are textbook numbers, unverified against your printer. Same caveat as Plate 01's ink ceilings — one test print settles both.

This plate does not decide

  • Pictogram construction for repeated concepts (next plate)
  • The hero illustration slot and its ink allowance
  • Methods-diagram primitives (arm, condition, flow, n-badge)

Known soft spots

  • Direct-label collision avoidance is a simple vertical push-apart — dense series (6+) may still crowd
  • Distribution jitter is deterministic-looking but not seeded; two reads of the same data draw differently
  • The claim graphics assume a positive, single-direction story; a claim with a null or mixed result has no honest glyph here yet
